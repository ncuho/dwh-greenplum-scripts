# Чтение согласованного снимка

Даёт существующей Airflow identity SELECT на двадцать объектов выбранной цепочки. Загрузчик открывает REPEATABLE READ READ ONLY, не меняет источник и не берёт блокировки записи. Права исполнения исходных бизнес-функций остаются отдельными правами исходного DAG. Доступ к rejects для проверки готовности уже указан в source_release_permissions.
