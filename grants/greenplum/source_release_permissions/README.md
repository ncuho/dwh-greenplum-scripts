# Права исходного расчёта

Разрешает Airflow читать журнал DDS и rejects для проверок согласованности. UPDATE checkpoint даёт возможность брать стандартную EXCLUSIVE-блокировку на время применения партии. Изменение бизнес-таблиц выполняют уже существующие SECURITY DEFINER функции `apply_batch`, `refresh_production`, `refresh_downtime`; отдельная миграционная SQL-служба больше не вызывается.
