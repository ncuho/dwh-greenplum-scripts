# production

Панель «Добыча по месторождениям · Greenplum». Содержит сохранённые графики, layout и фильтры региона/месторождения. Источник определяется соответствующим dataset; публикация release выполняется отдельно.

Код: [production.json](production.json).

## Статус сущности

- **GitHub:** код и описание находятся в этой папке.
- **Data Catalog:** Зарегистрирована отдельная карточка в Data Catalog.
- **Lakehouse:** Исходный BI продолжает читать Greenplum. Целевые dataset/dashboard — отдельные объекты.
