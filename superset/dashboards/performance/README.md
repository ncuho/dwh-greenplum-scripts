# performance

Панель «Эффективность добычи и простои · Greenplum». Содержит сохранённые графики, layout и фильтры региона/месторождения. Источник определяется соответствующим dataset; публикация release выполняется отдельно.

Код: [performance.json](performance.json).

## Статус сущности

- **GitHub:** код и описание находятся в этой папке.
- **Data Catalog:** Зарегистрирована отдельная карточка в Data Catalog.
- **Lakehouse:** Исходный BI продолжает читать Greenplum. Целевые dataset/dashboard — отдельные объекты.
