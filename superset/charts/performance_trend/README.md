# performance_trend

График «Динамика простоев по месторождениям». Использует dataset 5; параметры метрик, агрегации, временной гранулярности и отображения заданы в params.

Исходный код: [performance_trend.json](performance_trend.json).

## Статус сущности

- **GitHub:** код и описание находятся в этой папке.
- **Data Catalog:** Зарегистрирована отдельная карточка в Data Catalog.
- **Lakehouse:** Исходный BI продолжает читать Greenplum. Целевые dataset/dashboard — отдельные объекты.
