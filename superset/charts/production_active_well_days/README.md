# production_active_well_days

График «Активные скважино-дни». Использует dataset 4; параметры метрик, агрегации, временной гранулярности и отображения заданы в params.

Исходный код: [production_active_well_days.json](production_active_well_days.json).

## Статус сущности

- **GitHub:** код и описание находятся в этой папке.
- **Data Catalog:** Зарегистрирована отдельная карточка в Data Catalog.
- **Lakehouse:** Исходный BI продолжает читать Greenplum. Целевые dataset/dashboard — отдельные объекты.
