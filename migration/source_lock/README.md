# Согласованное чтение источника

`lock_c0` открывает окно INITIAL, `lock_c1` — REFRESH. Это обычный SQL GP/psql: BEGIN, timeout, advisory lock и SHARE-lock исходных таблиц. SELECT двух переносимых view удерживает их определения от DDL. Скрипты не создают схемы, функции или копии данных.

Перед запуском оператор приостанавливает GP connector, завершает source DAG и выключает его расписание. Во время переноса Kafka и Iceberg sink работают, исходные отчёты читаются, но GP не обновляется. Сессию psql держат до READY и сверок; затем COMMIT/ROLLBACK освобождает locks, а Resume и включение исходного DAG возобновляют обработку с прежних offsets.

JSON из открытой сессии передаётся в config целевого DAG. Runtime проверяет PID, database OID, virtualtransaction и фактические locks. Один BEGIN без блокировок не даёт общую границу независимым подключениям Cedrus. Target-компенсация выполняется отдельно от транзакции GP.
