# Окно чтения C1

При остановленной доставке в GP и завершённой исходной обработке открывает обычную транзакцию с SHARE-блокировками. Cedrus читает исходные таблицы напрямую. Сессия остаётся открытой до окончания загрузки и сверок; COMMIT или ROLLBACK освобождает блокировки. Генератор и Iceberg sink продолжают работать.
