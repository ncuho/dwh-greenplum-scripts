# Проверки

`python3 -B -m unittest discover -s tests -v` запускает локальные проверки состава SQL, путей и входных параметров. Они не подключаются к Greenplum и не выполняют SQL. `sql/` содержит проверки данных и поведения функций для отдельного согласованного запуска в базе; некоторые проверки изменяют данные внутри транзакций. Подробности и ограничения приведены в `docs/validation.md`.
