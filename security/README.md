# Доступ к исходному хранилищу

`read_only.sql` предоставляет существующей выделенной роли CONNECT, USAGE семи схем и SELECT ровно85 таблиц. Из PUBLIC убирается доступ к схеме ETL и исполнению её функций. Роль, пароль, сертификат, HBA и сетевые правила этим SQL не создаются.

```bash
psql -X -v ON_ERROR_STOP=1 -v database=og_dwh -v read_role=your_read_role -f security/read_only.sql
```

Это явная административная операция, не часть обычного чтения. Используйте выделенную роль без дополнительных собственных/унаследованных write-привилегий; приведённый GRANT не отменяет ранее выданные права других ролей. Проверенный runtime-reader имеет85 SELECT,0 write,0 EXECUTEETL; подключение к `og_dwh` с проверкой сертификата реально проверено после переименования. Credentials и конкретные сетевые адреса не публикуются.
