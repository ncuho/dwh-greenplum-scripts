# Установка SMT

Компилирует текущий `OilEnvelopeToStaging`, выполняет JVM-проверку сохранения JSON/координат и обязательного времени приёма, затем заменяет ровно один установленный класс. Старый JAR сохраняется за пределами plugin.path. Перезапускается только Iceberg Kafka Connect worker. GP ingestion не перезапускается.

Запускать из авторизованного рабочего пространства с существующими SSH bindings; код использует JDK Kafka VM и действующие библиотеки Connect/Iceberg. Секреты не входят в исходники или вывод. До запуска проверьте, что нет активной целевой миграции. После запуска проверьте каждую Connect task и ненулевой received_at реальной доставки.
