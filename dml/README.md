# Изменение данных и последовательность обработки

- `bootstrap/` — наполнение тестового экземпляра, включая справочники, события и детальные таблицы; порядок указан в `sources/bootstrap/`.
- `operations/` — вызовы функций построения витрин и пакетного расчёта.
- `maintenance/` — обновление материализованного представления.
- `proposed/` — подготовленное изменение плана, не применённое к серверу.

Текущий пакетный процесс составлен из SQL/PLpgSQL и последовательности вызовов. Подготовленный вариант ручного DAG без расписания находится в `orchestration/airflow`; он не развёрнут. Фактические внешние задания, SLA и зависимости в другом окружении требуют инвентаризации. Не запускайте эти файлы на существующем экземпляре без проверки: операции изменяют данные.
