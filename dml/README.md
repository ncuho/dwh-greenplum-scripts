# Изменение данных и последовательность обработки

- `bootstrap/` — наполнение тестового экземпляра, включая справочники, события и детальные таблицы; порядок указан в `sources/bootstrap/`.
- `operations/` — вызовы функций построения витрин и пакетного расчёта.
- `maintenance/` — обновление материализованного представления.

Текущий пакетный процесс составлен из SQL/PLpgSQL и последовательности вызовов. Отдельный планировщик и расписание кодом этого репозитория не определены. Фактические внешние задания, SLA и зависимости в другом окружении требуют инвентаризации. Не запускайте эти файлы на существующем экземпляре без проверки: операции изменяют данные.
