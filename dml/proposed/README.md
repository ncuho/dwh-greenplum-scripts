# Подготовленные изменения

`update_production_plan.sql` иллюстрирует исправление месячного плана по ключу и ожидаемому прежнему значению. При отсутствии совпадений UPDATE затронет ноль строк. В файле предусмотрен ROLLBACK: это вариант для рассмотрения, не действующий процесс. Перед применением требуется отдельно определить формат NULL-входов, права, согласование изменения, обновление витрин, конкурентные записи и аудит. Проверки на сервере не проводились.

Также подготовлены [вставка событий из внешней таблицы](ingestion/insert_repair_events.sql) и [удаление заказа при отсутствии двух известных связей](maintenance/delete_unlinked_repair.sql). Обе операции по умолчанию заканчиваются ROLLBACK; до исполнения нужна проверка конкурентных операций и всех зависимостей.
