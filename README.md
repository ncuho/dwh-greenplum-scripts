# Нефтегазовое DWH: демонстрация миграции

Два сценария на общем хранилище Greenplum: добыча по месторождениям и эффективность добычи с учётом простоев. Три слоя: `oil_stg`, `oil_dds` с историей в модели Raw Vault и `oil_mart` с фактами и измерениями.

`gp/` — DDL и загрузочные функции; `ingestion/` — контракт событий, генератор и интеграция Kafka; `quality/` — проверки; `metadata/` — спецификация зависимостей; `docs/` — семантика и порядок запуска. Данные синтетические, масса нефти выражается в тоннах, timestamps — UTC.

Статус: GP DDL применён и проверен отдельно в тестовой базе; подключение Kafka, данные, DAG, BI и сквозной lineage готовятся. Скрипты включают действия, которые создают/изменяют таблицы: перед запуском сверьте инструкции, окружение и права. Секреты хранятся вне репозитория.
