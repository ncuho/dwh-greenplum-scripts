# Greenplum: цепочка продаж для вебинара

Исходные объекты и учебный набор находятся в `commerce-demo/gp`, проект Kafka — в `commerce-demo/kafka`, модель и ограничения — в `commerce-demo/docs`. На стенде создан начальный набор событий из локальной фикстуры и рассчитана витрина; фиктивные позиции не являются Kafka offsets. Kafka и исходный Connect sink работают с пустым бизнес-топиком; согласованная граница миграции пока не подтверждена.

Это демонстрационная адаптация Data Vault и Kimball, не промышленное внедрение. Перед применением проверьте актуальные инструкции, права, совместимость и состояние стенда. Секреты не входят в репозиторий.
