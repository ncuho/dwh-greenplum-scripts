# Нефтегазовое DWH: демонстрация миграции

Два сценария на общем хранилище Greenplum: добыча по месторождениям и эффективность добычи с учётом простоев. Три слоя: `oil_stg`, `oil_dds` с историей в модели Raw Vault и `oil_mart` с фактами и измерениями.

`gp/` — DDL и загрузочные функции; `ingestion/` — контракт событий, генератор и интеграция Kafka; `quality/` — проверки; `metadata/` — спецификация зависимостей; `docs/` — семантика и порядок запуска. Данные синтетические, масса нефти выражается в тоннах, timestamps — UTC.

Статус 21 ноября 2026: в GP загружены 15 525 событий через Kafka Connect, рассчитаны две витрины и опубликованы два дашборда Superset. Ручной DAG `oil_gp_release` выполнен с успехом и снова остановлен; первая волна добычи загружена в DLH и сверена. Связи в Data Catalog зарегистрированы вручную по фактическому коду. Полный поток изменений/CDC, атомарность выпуска между системами и промышленная отказоустойчивость не заявляются. Скрипты включают действия, которые создают/изменяют таблицы: перед запуском сверьте инструкции, окружение и права. Секреты хранятся вне репозитория.
