# Greenplum: исходный DWH для демо миграции

Исходный код демонстрационного хранилища из вебинара о миграции Greenplum в Lakehouse на VK Data Platform.

Кейс построен на синтетических данных нефтедобычи: месторождения, скважины, суточная добыча и простои. События поступают через Kafka и Kafka Connect, обрабатываются функциями Greenplum под управлением Airflow и используются в двух отчётах Superset: по добыче и эффективности с учётом простоев.

В хранилище три слоя: **Stage (`oil_stg`)** для приёма событий, **DDS (`oil_dds`)** с hubs, links и satellites для ключей, связей и истории, **Marts (`oil_mart`)** с историческими измерениями, фактами и агрегатами.

Начните с архитектуры, затем откройте `oil_gp_release` и вызываемые им функции `apply_batch`, `refresh_production` и `refresh_downtime`.

Целевой DDL, Spark-логика и проверки переноса находятся в [репозитории Lakehouse](https://github.com/ncuho/dlh-scripts). В демо переносится цепочка добычи; исходный GP продолжает обслуживать оба отчёта.

Для запуска нужны настроенные сервисы, подключения и права доступа. В [migration/](migration/) сохранены дополнительные и исторические реализации миграционных механизмов.
