# Хранилище производственных данных Greenplum

Репозиторий содержит выбранный исходный SQL хранилища Greenplum 6.26.2: добыча по скважинам, производственный план, энергия и ремонт оборудования. Данные экземпляра синтетические. Состав ограничен объектами, необходимыми для разбора этих процессов; это не полная копия базы.

## Производственный процесс

Месячные показатели добычи из `ods.og_tbl_production_volume` распределяются по дням с учётом календаря, истории скважины и интервалов простоя. Функция `etl.rebuild_production_day` проверяет входные интервалы и записывает результат в `dds.fact_production_day`. При округлении остаток добавляется к последнему дню с положительным временем работы, чтобы сохранить месячную сумму.

Суточная таблица используется в представлении `dds.v_production_with_well`. Месячная витрина `dm.field_month_performance` содержит факт, план, затраты на энергию и простой по месторождению. Представление `dm.v_production_dashboard` добавляет название месторождения, а `dm.mv_field_month_energy` хранит агрегат затрат. Функция `etl.rebuild_marts` рассчитывает месячную витрину и ещё шесть витрин; часть её исходных и целевых таблиц в эту выборку не входит. `etl.run_daily_batch` последовательно вызывает суточный и сводный расчёты.

Физическая единица исходных показателей добычи не установлена. Часовой пояс исходных временных значений требует уточнения.

## Состав

| Каталог | Содержание |
|---|---|
| [`ddl/tables/ods`](ddl/tables/ods) | Месячная добыча, скважины и месторождения |
| [`ddl/tables/ref`](ddl/tables/ref) | Календарь и тарифы |
| [`ddl/tables/dds`](ddl/tables/dds) | История скважин, простои, суточная добыча, план, энергия и ремонты |
| [`ddl/tables/dm`](ddl/tables/dm) | Месячные витрины добычи и стоимости ремонта |
| [`ddl/tables/ctl`](ddl/tables/ctl), [`ddl/sequences`](ddl/sequences) | Учёт пакета и выполнения, последовательность идентификаторов |
| [`ddl/indexes`](ddl/indexes), [`ddl/types`](ddl/types), [`ddl/domains`](ddl/domains) | Индексы, перечисление состояния работ и тип тарифа |
| [`ddl/views`](ddl/views), [`ddl/materialized_views`](ddl/materialized_views) | Представления и агрегат энергии |
| [`functions/etl`](functions/etl) | Суточный и сводный расчёты, пакетный вызов, функции периода и стоимости энергии |
| [`dml`](dml) | Начальное наполнение добычи, завершение пакета, вызов расчёта и обновление агрегата |
| [`dql/dm`](dql/dm) | Выборки из месячных витрин |
| [`tests/sql/quality`](tests/sql/quality) | Проверки пересечения и покрытия версий истории скважин |

Описание связей, гранулярности и особенностей хранения — в [модели данных](docs/model.md). В каталоге `ddl` определения распределения, секционирования, сжатия и индексов сохранены как в исходных файлах. Описание внешних заданий, права всех пользователей и полная история потребителей в этой выборке отсутствуют.
