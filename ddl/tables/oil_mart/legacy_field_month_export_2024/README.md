# legacy_field_month_export_2024

Архивный месячный экспорт, исключённый из обеих волн. Значения получены из baseline 2025 с коэффициентом 0.95 и сдвигом дат на год; они не подтверждают фактическую добычу 2024 года. Плановый потребитель не настроен.

Исходный код: [legacy_field_month_export_2024.sql](legacy_field_month_export_2024.sql).

## Статус сущности

- **GitHub:** код и описание находятся в этой папке.
- **Data Catalog:** Зарегистрирована отдельная карточка таблицы в Data Catalog.
- **Lakehouse:** Исключена из обеих волн; рабочая цепочка от неё не зависит.
