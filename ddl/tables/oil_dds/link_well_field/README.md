# link_well_field

Хранит историческую связь скважины с месторождением по техническим ключам. Изменяемые атрибуты находятся в satellites.

Исходный код: [link_well_field.sql](link_well_field.sql).

## Статус сущности

- **GitHub:** код и описание находятся в этой папке.
- **Data Catalog:** Зарегистрирована отдельная карточка таблицы в Data Catalog.
- **Lakehouse:** Первая цепочка: перенесена в Iceberg на зафиксированной границе.
