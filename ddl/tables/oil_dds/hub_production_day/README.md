# hub_production_day

Хранит бизнес-идентификатор скважино-дня добычи и детерминированный hash key. Не содержит изменяемых описательных атрибутов.

Исходный код: [hub_production_day.sql](hub_production_day.sql).

## Статус сущности

- **GitHub:** код и описание находятся в этой папке.
- **Data Catalog:** Зарегистрирована отдельная карточка таблицы в Data Catalog.
- **Lakehouse:** Первая цепочка: перенесена в Iceberg на зафиксированной границе.
