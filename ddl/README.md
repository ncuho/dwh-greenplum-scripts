# Определения объектов

В `schemas`, `tables`, `indexes`, `views`, `materialized_views`, `types`, `domains` и `sequences` находятся SQL-определения исходной модели. В `proposed` размещаются подготовленные определения, которые не подтверждены в текущей базе. Порядок начального развёртывания задан в `sources/bootstrap`.

Файлы содержат команды создания объектов и не рассчитаны на повторное выполнение поверх существующей базы. Перед использованием проверьте права и зависимости.
