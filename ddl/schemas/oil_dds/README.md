# oil_dds

Схема интеграции и истории бизнес-сущностей с hubs, links и satellites.

Исходный код: [oil_dds.sql](oil_dds.sql).

## Статус сущности

- **GitHub:** код и описание находятся в этой папке.
- **Data Catalog:** Схема зарегистрирована в Data Catalog.
- **Lakehouse:** Одноимённый слой существует в Lakehouse; состав объектов различается по волнам.
