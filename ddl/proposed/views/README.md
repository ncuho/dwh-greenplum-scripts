# Подготовленные представления

Представления не созданы в базе. Порядок: сначала `v_repair_cost_by_well.sql`, затем зависящее от него `v_repair_order_overview.sql`. `v_shipment_month.sql` независимо от них. В ремонтном представлении NULL означает отсутствие строки затрат и не заменяется нулём. В отгрузках число строк — число строк документа, а не число документов; нулевые, NULL и отрицательные значения требуют отдельных бизнес-правил. До создания проверить имена, права, зерно, полноту, скорость и совпадение типов.
