# Подготовленные определения

`v_quality_assessment_by_well.sql` — подготовленное представление для обзора качества по скважине и показателю. Не зарегистрировано и не испытано на сервере. Неизвестный результат подсчитывается отдельно от нарушений. Перед развёртыванием требуются согласование определения показателя, проверка прав и стоимости запроса.

Дополнительно подготовлены [внешняя таблица gpfdist](external/README.md) и [зависимые представления](views/README.md); условия и порядок указаны в их описаниях.
