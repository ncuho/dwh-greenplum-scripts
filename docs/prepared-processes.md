## Границы синтаксиса и применения

Справочник [команд Greenplum 6](https://docs-cn.greenplum.org/v6/ref_guide/sql_commands/sql_ref.html) перечисляет INSERT, UPDATE и DELETE, но не содержит SQL-команды MERGE. `MODE: MERGE` в [gpload](https://docs-cn.greenplum.org/v6/utility_guide/admin_utilities/gpload.html) относится к режиму утилиты и не доказывает поддержку отдельного SQL MERGE. Для предполагаемого обновления и вставки нужно отдельно разработать транзакционный процесс с проверкой уникальности входа, конкурентных запусков, ошибок и повтора; здесь готового универсального upsert нет.

[Синтаксис UPDATE для GP 6](https://docs-cn.greenplum.org/v6/ref_guide/sql_commands/UPDATE.html) в справочнике не указывает RETURNING, поэтому подготовленный файл использует отдельный SELECT. [DELETE](https://docs-cn.greenplum.org/v6/ref_guide/sql_commands/DELETE.html) документирует RETURNING. Совпадение синтаксиса с документацией не подтверждает проверку конкретного SQL сервером, состояние расширений или правильность бизнес-правил.

Управление внешним потоком, полная история изменений, источник инкрементов, восстановление после переключения и права на подготовленные объекты не настроены. Перенос данных не запускается кодом из этого раздела.
