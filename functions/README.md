# Функции обработки

`etl/` содержит функции SQL и PL/pgSQL исходной базы. `rebuild_production_day`, `rebuild_marts` и `run_daily_batch` изменяют данные; служебные функции и отрицательные проверки описаны в `docs/business-logic.md`. Функции не являются самостоятельным расписанием. Перед запуском необходимо проверить входы, права, транзакцию и зависимости.

`proposed/` содержит подготовленные определения функций, которые не созданы на сервере.
