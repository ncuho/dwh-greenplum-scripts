# refresh_downtime

После production refresh выбирает актуальные интервалы, проверяет активный скважино-день и отсутствие пересечений, рассчитывает часы и дневные суммы.

Тип: хранимая функция PL/pgSQL Greenplum 6; это не процедура CALL.

Исходный код: [refresh_downtime.sql](refresh_downtime.sql).

## Статус сущности

- **GitHub:** код и описание находятся в этой папке.
- **Data Catalog:** Отдельной карточки функции нет; обработка отражена в описаниях DAG и lineage.
- **Lakehouse:** Бизнес-расчёт адаптирован к Cedrus SQL; GP-функция не переносится как исполняемый PL/pgSQL-объект.
