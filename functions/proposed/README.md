# Подготовленные функции

Функции не созданы и не выполнялись в Greenplum. `plan_attainment_pct` возвращает NULL при нулевом или неизвестном плане; `valid_half_open_interval` проверяет только порядок заданных дат; `require_nonnegative` отклоняет NULL и отрицательные значения. Математика и имена требуют согласования с владельцами показателей. Типы округления, границы, права и выполнение SQL/PLpgSQL следует испытать на отдельном экземпляре GP 6 до использования.
