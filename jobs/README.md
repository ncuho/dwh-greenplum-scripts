# Подготовленное задание чтения

`export_field_month.py` — отдельное задание на чтение существующей `dm.field_month_performance` с диапазоном полных месяцев и выводом CSV в stdout. В базе данные не изменяет: соединение устанавливает режим только для чтения. Задание не развёрнуто и не выполнялось. Нужны Python, psycopg2, libpq service и права SELECT; фактические зависимости и подключение не проверены. Конкретную команду запуска и место хранения выгрузки следует согласовать отдельно, поскольку результат может содержать данные ограниченного доступа.

При закрытии приёмника CSV задание может завершиться ошибкой. Формат значений и обработку NULL принимающая система должна согласовать; CSV сам по себе не обеспечивает сохранение типов и различие между пустой строкой и NULL.
