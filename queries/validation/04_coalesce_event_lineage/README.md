# Проверка происхождения объединённых событий

Проверяет обе карты coalesce и фактические доставки по topic, partition и offset. Каждая запись аудита должна ссылаться на существующую исходную партию и на событие в итоговой партии. Ноль нарушений означает согласованность карты.

Тот же SELECT выполняет `validate_coalesce_audit` в `oil_gp_release` после `bridge_capture.prepare_source` и до commit. Ошибка откатывает source release. Запрос только читает данные.
