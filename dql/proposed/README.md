# Подготовленные запросы проверки

Запросы не запускались на сервере. Проверки охватывают пропуски между имеющимися значениями телеметрии (границы периода и дубли отдельно), неизвестную лабораторную оценку, строки отгрузки без документа и дубли или пустой ключ внешнего файла ремонтов. Запрос внешнего файла требует заранее созданной `stg.ext_repair_event`; его выполнение обращается к gpfdist. Найденные расхождения не исправляются автоматически.
