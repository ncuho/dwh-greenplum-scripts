# Запросы для чтения

- `dm/` — выборки полей семи расчётных витрин. Они входят в набор, проверенный контрактными тестами структуры SQL.
- `ad_hoc/` — новые учебные примеры по таблицам этой модели: план и факт добычи, результаты лабораторных анализов и длительность ремонта. Исходные таблицы и поля сверены с DDL в репозитории; запросы не исполнялись на Greenplum, значения и планы выполнения не проверены.

Запрос план/факт считает факт до соединения, затем соединяет его с базовым сценарием. Значения исходной добычи имеют неустановленную физическую единицу. В лабораторном запросе неизвестный результат считается отдельно и не приравнивается к успешному или нарушению. Длительность ремонта возвращается только для строк с двумя датами; отрицательные интервалы требуют отдельной проверки качества.

Перед использованием проверьте права, объём чтения, временную зону, определения показателей и соответствие доступным данным. Эти примеры не доказывают наличие аналогичных запросов у пользователей действующего хранилища.
