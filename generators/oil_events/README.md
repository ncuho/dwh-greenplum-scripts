# oil_events

Программный источник событий месторождений, скважин, добычи и простоев. Baseline воспроизводим по seed; delta включает correction, replay, delete, late arrival и версию well.

Исходный код: [oil_events.py](oil_events.py).

## Статус сущности

- **GitHub:** код и описание находятся в этой папке.
- **Data Catalog:** Отдельной карточки нет; служебная реализация описана в коде и документации.
- **Lakehouse:** Не переносится как объект данных; используется для эксплуатации или настройки.
