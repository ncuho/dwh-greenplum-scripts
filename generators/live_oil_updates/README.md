# Непрерывные уточнения добычи

Отправляет новую версию существующего скважино-дня каждые десять секунд. Количество тонн меняется в небольшом диапазоне относительно исходного seed 42; бизнес-ключ остаётся прежним. Версия монотонна, envelope и сериализация переиспользуют `oil_events.py`.

Запускается до C0 и продолжает работать во время capture и исторической загрузки. Ctrl+C завершает текущую отправку и останавливает цикл. `--resume` продолжает поток по локальному checkpoint; при неизвестном результате отправки повторяется тот же сохранённый event_id.

Команда на Kafka VM: `sudo -u kafka env PYTHONPATH=/opt/kafka-demo/generator/site python3 /opt/kafka-demo/oil-generator/live_oil_updates.py --interval 10`.

Это producer. Применение GP выполняет отдельный `oil_gp_release`, при включённом DAG — раз в минуту. Сам генератор не изменяет таблицы GP напрямую.
