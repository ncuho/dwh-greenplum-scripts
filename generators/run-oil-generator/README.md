# run-oil-generator

Запускает источник событий с настроенным TLS-подключением Kafka. Выполняется оператором явно.

Исходный код: [run-oil-generator.sh](run-oil-generator.sh).

## Статус сущности

- **GitHub:** код и описание находятся в этой папке.

- **Lakehouse:** Не переносится как объект данных; используется для эксплуатации или настройки.
